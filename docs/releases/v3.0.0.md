# Release v3.0.0

Commit: `6ae5742`  
Date: 2026-04-24

## Summary

Major platform rebuild focused on enterprise readiness, reliability, and long-term scalability.

- Rebuilt as a workspace monorepo (`apps/*`, `packages/*`).
- Migrated auth to Clerk and billing to Stripe with webhook-driven sync.
- Added worker/runtime scaffolding for async voice jobs.
- Improved production audio reliability (CSP, playback behavior, richer error output).
- Hardened XTTS runtime and long-text cloned-voice generation.

## Highlights

### Monorepo architecture
- New application boundaries:
  - `apps/web`: Next.js 16 App Router frontend + API layer
  - `apps/workers`: async queue worker
  - shared packages in `packages/*`
- Root scripts now orchestrate workspace tasks.

### Auth and billing foundation
- Clerk sign-in/sign-up and org-aware sync via `/api/webhooks/clerk`.
- Stripe webhook ingestion via `/api/webhooks/stripe`.
- Entitlement mapping and subscription persistence added in shared billing package.

### Reliability and UX
- `middleware` deprecation addressed by moving to `apps/web/proxy.ts`.
- Production CSP updated for media playback (`media-src blob:`).
- UI now surfaces backend TTS error context (`details`, `hint`, `requestId`) instead of generic failures.

### XTTS and cloned voice improvements
- Compatibility fixes for local XTTS startup (`transformers`/`torch` pinning, writable voice dir fallback).
- Adaptive timeout behavior for cloned-voice and longer requests.
- Automatic long-text chunking with server-side WAV stitching for cloned voices.

## Breaking changes

- Root app structure moved to `apps/web` and `apps/workers`.
- Legacy NextAuth route removed.
- Root-level `next.config.js`, `middleware.ts`, and related config locations moved under `apps/web`.
- Environment variable expectations changed (Clerk, Stripe, DB/Redis, XTTS).

## Upgrade notes

1. Install dependencies and run workspace-aware scripts:
   - `npm install`
   - `npm run dev`
   - `npm run build`
2. Configure required environment variables in each environment:
   - Clerk: `NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY`, `CLERK_SECRET_KEY`, `CLERK_WEBHOOK_SIGNING_SECRET`
   - Stripe: `STRIPE_SECRET_KEY`, `STRIPE_WEBHOOK_SECRET`, `STRIPE_PRICE_ID_*`
   - Data: `DATABASE_URL`, `REDIS_URL`
   - XTTS: `XTTS_URL` (when cloning/effects pipeline should be active)
3. Run DB schema setup for the new package layout:
   - `cd packages/db && DATABASE_URL=... npx drizzle-kit push --config=drizzle.config.ts`
4. Validate launch readiness with:
   - `docs/LAUNCH_CHECKLIST.md`
