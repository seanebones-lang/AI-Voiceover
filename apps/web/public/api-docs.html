      "category": "standard",
      "engine": "kokoro",
      "available": true
    }
  ],
  "default_count": 34,
  "cloned_count": 0
}
POST /api/tts

Generate speech from text using a specified voice.

Request Body

{
  "text": "Hello, this is NextEleven speaking.",
  "voice_id": "default_english",
  "language": "en"
}

Parameters

Parameter Type Required Description
text string Yes Text to convert (max 5000 chars)
voice_id string Yes Voice ID from /api/voices
language string No Language code (default: en). Stock voices use their own language; cloned and studio voices accept any of the 17 XTTS languages.
output_format string No wav (default, lossless) or mp3

Text markup: [pause], [pause:short|medium|long] insert real silence; blank lines add a paragraph pause; [ipa:word|phonemes] sets pronunciation (exact phonemes on stock voices).

Response

Returns an audio file (audio/wav or audio/mpeg). All synthesis runs on the self-hosted voice service; no third-party TTS API is called.

POST /api/clone-voice

Clone a voice from audio samples. Requires multipart/form-data.

⚠️ Requires explicit consent from voice owner

Form Parameters

Parameter Type Description
name string Name for the cloned voice
description string Optional description
files file[] Audio files (1-5, WAV/MP3)

Response

{
  "success": true,
  "voice_id": "clone_my_voice",
  "name": "My Voice",
  "samples_count": 2,
  "message": "Voice cloned successfully!"
}
GET /api/cloned-voices

Retrieve all cloned voices.

Response

{

      "source": "cloned"
    }
  ]
}
