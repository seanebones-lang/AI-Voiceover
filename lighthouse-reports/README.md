# Lighthouse Reports

This directory contains Lighthouse CI reports generated by running:

```bash
npm run lighthouse
```

## Files

- `home.report.html` - Interactive HTML report for home page
- `home.report.json` - JSON data for home page
- `playground.report.html` - Interactive HTML report for playground page
- `playground.report.json` - JSON data for playground page
- `summary.md` - Markdown summary of all reports

## Viewing Reports

Open the HTML files in your browser to view interactive Lighthouse reports.

## Generating Reports

1. Build the application: `npm run build`
2. Start the server: `npm start`
3. Run Lighthouse: `npm run lighthouse`

Reports will be automatically generated in this directory.
